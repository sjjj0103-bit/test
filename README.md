# 오늘 뭐 입지? 👗

내 옷장 사진을 올려 두면 **오늘·이번 주 날씨**와 **일정(출근 / 데이트 / 외출)**에 맞춰 코디를 추천해 주는 웹사이트예요.
휴대폰 브라우저에서 바로 쓸 수 있고, 회원가입이나 설치가 필요 없어요.

## 할 수 있는 것

- **글로 옷 목록 등록**: "베이지 니트", "연청 청바지 (출근)", "기모 회색 맨투맨"처럼 한 줄에 하나씩 적으면 종류·색·두께를 알아서 채워 줘요.
- **사진으로 옷 등록 + AI 배경 지우기**: 옷 사진을 고르면 AI가 배경을 자동으로 지워 옷만 남겨요. 덜 지워진 곳은 지우개·되살리기 붓으로 다듬을 수 있어요. AI는 이 기기 브라우저 안에서만 돌아가서 사진이 밖으로 나가지 않고 비용도 들지 않아요(처음 한 번 약 55MB 내려받기).
- **무늬·디테일**: 스트라이프·체크·도트·꽃무늬·프린팅과 무늬 색까지 저장해요. "하늘색 흰 스트라이프 반팔티"처럼 적으면 알아서 인식하고, 아바타에도 무늬가 그려져요.
- **아바타 입혀보기**: 배경을 지운 **실제 옷 사진**을 아바타에 입혀 보거나(크기·위치 조절 가능), 핀터레스트처럼 옷을 펼쳐 놓은 **코디 보드**로 볼 수 있어요. 사진이 없는 옷은 그림으로 보여 줘요. 내 옷을 눌러 아바타에게 직접 입혀 보고, 오늘 날씨에 두께가 맞는지·색이 어울리는지 바로 평가해 줘요. 마음에 드는 코디는 ⭐ 저장할 수 있어요.
- **오늘의 코디 3가지**: 체감온도, 출근길(8시) 기온, 일교차, 비 올 확률을 보고 추천해요. 왜 이 조합인지도 함께 알려 줘요.
  - 예: "체감 12°에 딱 맞는 두께예요", "네이비+베이지는 공식 같은 조합이에요"
- **이번 주 코디 미리 짜기**: 7일치 날씨를 보고, 같은 옷이 겹치지 않게 요일별 코디를 짜 줘요.
- **비슷한 코디 사진 찾기**: 추천된 조합으로 핀터레스트·네이버 이미지·구글 이미지 검색을 바로 열어요. 핀터레스트가 로그인을 요구하면 네이버나 구글로 보면 돼요.
- **입은 옷 기록**: "이거 입을래요"를 누르면, 최근 3일 동안 입은 옷은 덜 추천해요.

## 추천 기준 (쉽게 설명)

1. **두께**: 한국에서 흔히 쓰는 "기온별 옷차림표"를 그대로 따라요. 옷마다 두께를 1~5단계로 매기고, 그날 체감온도에 맞는 단계를 골라요.
   - 28° 이상: 반팔·반바지 / 17~19°: 얇은 니트·가디건 / 9~11°: 트렌치코트 / 4° 이하: 패딩
2. **색 조합**: 블랙·화이트·베이지·네이비·데님 같은 기본색은 무엇과도 어울린다고 보고, 눈에 띄는 색(포인트 컬러)은 한 가지만 쓰는 조합에 점수를 더 줘요.
3. **일정**: 옷에 "출근"을 표시해 두면 출근하는 날 우선으로 추천해요.

## 알아 두세요

- 옷 사진과 기록은 **내 휴대폰 브라우저 안에만** 저장돼요. 어디에도 올라가지 않아요.
  그래서 폰을 바꾸거나 인터넷 기록을 지우기 전에는 **옷장 탭 → 백업 파일 저장**을 눌러 두세요.
- 날씨는 무료 날씨 서비스 [Open-Meteo](https://open-meteo.com/)에서 가져와요.
- 휴대폰에서 **"홈 화면에 추가"**를 누르면 앱처럼 아이콘으로 열 수 있어요.

## 사이트로 공개하는 법 (GitHub Pages, 무료)

1. 이 저장소의 **Settings → Pages**로 들어가요.
2. **Source**를 `Deploy from a branch`로 두고, Branch는 `main`, 폴더는 `/ (root)`를 고른 뒤 **Save**를 눌러요.
3. 1~2분 뒤 `https://sjjj0103-bit.github.io/test/` 주소로 접속할 수 있어요.

# 홀덤 코치 (`holdem/`)

홀덤펍에 가기 전에 연습하는 페이지예요. 2~9명이 앉는 테이블에서 컴퓨터, 친구와 함께 치면서, 내가 고를 때마다 **더 좋았을 선택**을 알려 줘요.

- **혼자 연습**: 나 + 컴퓨터 여러 명 (인원 2~9명, 컴퓨터 쉬움 / 보통 / 어려움 / 프로).
- **친구와 함께 (QR, 로그인 필요 없음)**: 친구들이 QR이나 링크로 들어오고, 빈자리는 컴퓨터가 채워요. 방장 폰과 친구 폰이 브라우저끼리 직접 연결되고(PeerJS), 각자의 카드는 그 사람에게만 보내요.
- **GTO 기반 컴퓨터 (프로·어려움)**: 169가지 시작 패의 승률 순위로 "상위 몇 %"를 계산하고, 자리(뒤에 남은 인원)와 칩 깊이(BB)마다 표준 범위(오픈·3벳·올인)로 판단해요. 상대 행동으로 상대 범위를 좁혀 승률을 다시 계산하고, 팟 오즈·드로우·포지션·SPR로 베팅/콜/폴드를 확률적으로 섞어요. 코치도 프리플랍에서 같은 기준으로 "이 자리 표준 범위는 상위 28%, 내 패는 상위 24%"처럼 설명해요.
- **대회 모드 (50~1000명)**: 우리 테이블은 직접 치고, 다른 테이블은 한 판씩 함께 진행돼요. 인원이 줄면 테이블을 합치고 인원을 맞춰요(리밸런싱). 사람(나와 친구)은 항상 같은 테이블. 상위 15% 입상, 파이널 테이블까지.
- **홀덤펍 토너먼트처럼**: 블라인드가 6판마다 올라가고, 칩을 다 잃으면 탈락해서 최종 순위가 나와요. 사이드 팟도 계산해요.
- **자리 표시**: BTN, SB, BB, UTG, HJ, CO 같은 자리 이름과 그 자리에서의 요령을 알려 줘요.
- 선택마다 **100점 만점 점수**, "왜 그런지", "이렇게 했으면 더 좋아요"를 내 승률, 필요한 승률, 상대 수와 함께 설명해요.
- **힌트 보기** 버튼으로 원할 때만 추천을 볼 수 있어요.
- **배경음악·효과음** 켜기/끄기.
- **기록실 (자동 저장)**: 한 판이 끝날 때마다 내 카드, 바닥 카드, 진행 기록, 내 선택 점수를 저장해요. 게임마다 등급, 평균 점수, 최종 순위(누가 몇 위였는지)도 저장해요.
  - 요약: 게임 수, 핸드 승률, 전체 평균 점수, 우승 횟수, 점수 흐름 그래프, 자주 하는 실수, 자리별 성적, 가장 크게 이긴/진 판
  - 게임 순위: 점수 높은 순 / 최근 순, 게임마다 최종 순위표
  - 핸드 기록: 이긴 판 / 진 판 / 아쉬운 선택 있는 판으로 걸러 보기
- **플레이어 분석 (기록실 → 플레이어 분석)**: 같이 친 사람(컴퓨터·친구·나)마다 참여율(VPIP), 프리플랍 레이즈(PFR), 공격 비율, 베팅 받으면 폴드하는 비율, 쇼다운까지 가는 비율을 계산해서 바위형, TAG, LAG, 콜링 스테이션, 매니악 같은 스타일로 정리하고 "이 사람 상대법"을 알려 줘요. 쇼다운에서 보여 준 패도 모아 줘요. 테이블에서 자리를 누르면 그 사람 분석이 바로 떠요.
- **성격 있는 컴퓨터**: 컴퓨터마다 실제 펍에서 만날 법한 성격(바위형, 콜링 스테이션, TAG, LAG, 매니악, 균형형)이 숨어 있어요. 분석으로 알아낸 뒤 "정답 확인"으로 맞혔는지 볼 수 있어요.
- **코치 피드백 팝업**: 화면 오른쪽 아래 버튼을 누르면 스크롤 없이 바로 피드백과 힌트가 떠요.
- 친구 초대는 GitHub Pages 주소(`https://sjjj0103-bit.github.io/test/holdem/`)에서 해야 해요. claude.ai 안에서는 외부 연결이 막혀 있어서, 거기서 누르면 이 주소로 안내해요.
- GitHub Pages를 켜 두었다면 `https://sjjj0103-bit.github.io/test/holdem/` 에서 열 수 있어요.
