# 📝 영어 단어 받아쓰기 (크롬북용)

학생이 크롬북으로 링크를 열면 **영어 단어가 소리로 나오고**, 학생이 철자를 써서 제출하면
**자동 채점**돼서 선생님의 **구글 시트**에 결과가 쌓이는 프로그램이에요.

- 비용 0원, 서버·설치 필요 없음 (구글 시트 + 구글 Apps Script만 사용)
- 8개 반을 한 링크로 처리 (학생이 반·번호·이름을 고름)
- 결과는 `결과` 탭에 한 줄씩 쌓이고, 메뉴 한 번으로 **반별 성적표** 탭을 만들어 줌

> **Apps Script(앱스 스크립트)** = 구글 시트에 붙어 있는 "작은 프로그램 넣는 칸"이에요.
> 엑셀의 매크로 같은 거라고 생각하면 돼요. 코드를 이해할 필요는 없고 **복사 → 붙여넣기**만 하면 돼요.

---

## 처음 한 번만 하는 설정 (약 10분)

### 1단계. 구글 시트 만들기
1. 학교 구글 계정(크롬북에 쓰는 계정과 같은 학교 계정 추천)으로 [sheets.new](https://sheets.new) 접속
2. 제목을 `영어 받아쓰기`로 바꾸기

### 2단계. 코드 붙여넣기
1. 시트 위쪽 메뉴 **확장 프로그램 → Apps Script** 클릭 → 새 탭이 열림
2. 왼쪽 `Code.gs`에 있는 내용을 전부 지우고, 이 폴더의 **[Code.gs](Code.gs)** 내용을 통째로 복사해서 붙여넣기
3. 왼쪽 **파일 옆 ＋ → HTML** 클릭 → 이름을 `Index`로 입력 (대문자 I, `.html`은 자동으로 붙음)
4. 안에 있는 내용을 지우고 **[Index.html](Index.html)** 내용을 통째로 붙여넣기
5. 위쪽 💾(저장) 클릭

### 3단계. 시트 탭 자동으로 만들기
1. Apps Script 위쪽 함수 선택 칸에서 `setupSheets` 고르고 **▶ 실행**
2. "권한 필요" 창이 뜨면 **권한 검토 → 내 계정 선택 → 허용**
   (내가 만든 프로그램이 내 시트에 쓰는 걸 허락하는 단계라 안전해요. "확인되지 않은 앱" 경고가 나오면 **고급 → (안전하지 않음)으로 이동** 누르기)
3. 시트로 돌아가면 `단어목록`, `단원설정`, `결과` 탭이 생겨 있어요.

### 4단계. 학생용 링크 만들기 (배포)
1. Apps Script 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴 ⚙ → **웹 앱** 선택
3. 이렇게 설정:
   - **다음 사용자 인증 정보로 실행**: `나`
   - **액세스 권한이 있는 사용자**: `(우리 학교 도메인) 내 모든 사용자`
     - 학생 계정이 선생님과 같은 학교 구글 계정이면 이걸 고르세요. 결과에 학생 이메일도 자동 기록돼요.
     - 학생 계정이 다른 곳이면 `모든 사용자`를 고르세요.
4. **배포** → 나오는 **웹 앱 URL**이 학생용 링크예요. 복사해 두세요.

### 5단계. 학생에게 링크 주기
- **구글 클래스룸** 수업 자료에 링크 올리기 (가장 편함)
- 또는 **QR 코드**로: 크롬에서 그 링크를 연 뒤, 주소창 오른쪽 **공유 아이콘 → QR 코드 만들기** → 다운로드해서 TV 화면에 띄우기
- 크롬북에서 학생이 **북마크(즐겨찾기)** 해 두면 다음부터 바로 들어가요.

## 평소에 쓰는 법

### 단어 넣기 — `단어목록` 탭
| 단원 | 단어(정답) | 뜻(학생에게 보임) |
|---|---|---|
| Unit 3 | elephant | 코끼리 |
| Unit 3 | How old are you? | 너는 몇 살이니? |

- 아이스크림 교과서의 단원별 필수 단어를 그대로 옮겨 적으면 돼요. 문장도 넣을 수 있어요.
- `뜻` 칸을 비워 두면 학생은 소리만 듣고 써야 해요(더 어려운 버전).
- 💡 단어가 많으면 교과서 단어표를 사진 찍어 ChatGPT·Claude에게 "단원 | 영어 | 뜻 3칸 표로 만들어 줘"라고 하고 붙여넣으면 빨라요.

### 단원 열고 닫기 — `단원설정` 탭
- A칸에 단원 이름(단어목록과 **똑같이**, 예: `Unit 3`)을 쓰고, B칸 체크박스에 ✅ 하면 학생 화면에 나타나요.
- 시험 끝난 단원은 체크를 풀면 학생 화면에서 사라져요.

### 결과 보기
- `결과` 탭: 제출 시각, 반, 번호, 이름, 단원, 점수, 틀린 단어(학생이 쓴 답)가 쌓여요.
- 시트 위쪽 메뉴 **📝 받아쓰기 → 반별 성적표 만들기** 누르면 `1반 성적` ~ `8반 성적` 탭이 생겨요.
  - 학생(줄) × 단원(칸) 표, **처음 본 점수** 기준이에요. 여러 번 했으면 `80 (3회)`처럼 표시돼요.
  - 결과가 더 쌓이면 메뉴를 다시 누르면 새로 고쳐져요.

## 채점 기준
- 대문자·소문자 차이는 무시 (`Apple` = `apple`)
- 앞뒤 공백, 띄어쓰기 여러 칸은 무시
- 문장 끝 마침표/물음표/느낌표는 없어도 정답 (`I like apples` = `I like apples.`)
- 그 외 철자가 하나라도 다르면 오답

## 학생 화면 기능
- 문제가 열리면 자동으로 단어를 읽어 줌, 🔊로 다시 듣기, 🐢로 천천히 듣기
- 맞춤법 자동 고침·붙여넣기 꺼 둠 (크롬북이 철자를 대신 고쳐 주지 않게)
- 제출 전에 내 답 전체 확인·수정 가능, 제출 후 점수와 정답 확인
- 한 번 입력한 반·번호·이름은 그 크롬북에 기억됨

## 설정 바꾸기 (`Code.gs` 맨 위)
| 설정 | 뜻 |
|---|---|
| `CLASS_COUNT = 8` | 반 수 |
| `SHUFFLE_WORDS = true` | 학생마다 문제 순서 섞기 (`false`면 시트 순서대로) |
| `SHOW_ANSWERS_AFTER = true` | 제출 후 정답 보여 주기 (`false`면 점수만) |

> 코드를 고친 뒤에는 **배포 → 배포 관리 → ✏ 수정 → 버전: 새 버전 → 배포**를 눌러야 학생 화면에 반영돼요. (링크는 그대로예요)

## 알아 두세요
- 소리는 크롬북에 들어 있는 영어 음성(구글 TTS = 글자를 소리로 읽어 주는 기능)을 써요. 학생들은 **이어폰**을 쓰는 게 좋아요.
- 이름은 학생이 직접 입력해서 다른 친구 이름으로 낼 수도 있어요. 학교 계정 도메인으로 배포하면 `계정` 칸에 실제 이메일이 남아서 확인할 수 있어요.
- 학생 화면이 정답을 소리로 읽으려면 단어를 크롬북으로 보내야 해서, 개발자 도구를 열 줄 아는 학생이라면 정답을 볼 수는 있어요(초등학생에겐 거의 해당 없음).
